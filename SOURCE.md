# Source

This repository is an ASC Team study fork. It is not an official ASC Committee repository, and it is not a university endorsement.

- Contest: ASC26 (2026)
- Upstream: https://github.com/ASC-Competition/ASC26-Embodied-World-Model-Optimization
- This fork: https://github.com/hkust-asc/asc2026-embodied-world-model

## What is in this fork

Official committee materials for the Embodied World Model challenge, including `psnr_score_for_challenge.py` and packaged camera/task data. The official finals notification also lists a separate software download at https://github.com/unitreerobotics/unifolm-world-model-action (not forked here).
